# `image_gen` 提示词

填好全部变量，仅保留本次采用的布局。无辅助词时，删除【固定文字风格】中的辅助关键词要求。此模板定义固定视觉风格，不按文章重新发明风格。

## 主提示词

```text
Use case: ads-marketing
Asset type: 微信公众号文章封面

制作可直接用于文章封面的平面图片，不是展示海报或设备样机。

【确切文字】
主文案：「{{主文案}}」
辅助关键词：{{辅助关键词，逐项加引号；没有则写“无”}}
仅呈现这些文字，逐字准确。全文摘要、关键词依据和设计说明均不出现在画面中。

【配色】
主色：{{颜色名称与 HEX}}
辅助色：{{颜色名称与 HEX}}
小面积点色：{{颜色名称与 HEX，或“无”}}
文字色：{{颜色名称与 HEX}}
主色形成基底，辅助色形成流动层次，点色仅占小范围。标题区域保持稳定、清晰的明暗对比。HEX 为外观参考。

【固定背景】
抽象流体 shader 美学。以低频噪声扭曲形成 2–3 个大尺度色场，呈柔和弧形与宽阔流带，边界模糊、过渡连续，有轻微明暗层次。辅助色在每张封面的右下方形成柔和的内部透光。标题背后保持低细节和稳定底色。

覆盖细密、均匀、低对比的单色胶片颗粒。颗粒可见但克制，缩略图仍以大色块为主。背景柔软，文字锐利，颗粒与模糊只作用于背景。

保持通透、克制、有空气感的系列外观。不加入具象物体、风景、人物、UI、图标、金属液体、玻璃球、霓虹线网、粗砂或脏斑。

【固定文字风格】
使用粗重、现代、无衬线中文黑体，字形简洁厚实；中英文混排保持视觉字重协调。主文案左对齐，文字组垂直接近所在封面的视觉中心，行距紧凑，字号醒目。
辅助关键词使用同一家族字体，小于主文案、保持缩略图可读性，整齐放在主文案下方，不散落成词云。
文字为单一纯色，轮廓清晰，无描边、阴影、渐变填充或立体效果。不额外添加副标题、英文、Logo、角标或装饰字。

【布局】
{{填入下方选定的一种布局}}

【系列一致性】
固定字形观感、颗粒强度、色场尺度、柔光方向和留白节奏。不同文章可更换配色和文案；同一文章的不同尺寸保持配色、文字内容与材质一致。
```

## 布局选择

默认用双版母版；用户只要单版或指定其他尺寸时遵循请求。以下尺寸是本模板设计规格，不宣称是平台实时要求。

### 双版母版

```text
目标尺寸 2010×600 px，宽高比 3.35:1。左右是两张独立设计的封面，无间隔拼接。

左侧为 1410×600 px、2.35:1 横版，占总宽度约 70.15%。主文案优先 1–2 行；左侧留白约为横版本身宽度的 8%，上下留白至少为高度的 12%。

右侧为 600×600 px、1:1 方版，占总宽度约 29.85%。对同一文案重新排字，主文案允许 2–3 行，四周留白至少为边长的 10%。色场适配方形构图。

两版各自包含完整主文案及指定的全部辅助关键词，任何文字都不跨越拼接边界。方版独立排版，不从横版机械截取。各版完整性优先于拼接处背景连续。
不绘制边框、分隔线、尺寸、比例或裁切标记。
```

### 单独横版

```text
目标尺寸 1410×600 px，宽高比 2.35:1。画面只有一张横版封面。
主文案优先 1–2 行，左侧留白约为宽度的 8%，上下留白至少为高度的 12%。
完整呈现主文案及指定的辅助关键词，全部文字只出现一次。
```

### 单独方版

```text
目标尺寸 600×600 px，宽高比 1:1。画面只有一张方版封面。
主文案允许 2–3 行，四周留白至少为边长的 10%。
完整呈现主文案及指定的辅助关键词，全部文字只出现一次。
```

## 排版适配

先确定可容纳的文字，再提交 `image_gen`。长文案优先换行，适度调整字号；用户指定的文字仍无法清楚容纳时，询问是否允许缩短，不静默删词。自主提炼的文案可在生成前继续压缩，但保留事实和含义。需要减少辅助词时，在选定文案阶段处理，横版与方版采用同一组最终文字。
