# 开头切入

从正文中挑一个具体入口。下面的例子只演示写法，其中的经历、事件与结果须由当前材料支持。

| 入口 | 写法示例 | 后面接什么 |
| --- | --- | --- |
| 一件正在做的事 | 昨天整理项目时，我又花了一遍时间找上次停在哪。 | 实际困境、尝试与发现 |
| 一个意外结果 | 配置只改了一行，原先失败的请求就通过了。 | 改了哪里，为什么会有这个结果 |
| 一个具体疑问 | 同一份配置，为什么换台机器就跑不起来？ | 排查过程与关键证据 |
| 一个近期变化 | 这次更新增加了本地导出，我想看看能不能把旧笔记迁过去。 | 与作者需求有关的变化和验证 |
| 一个有边界的判断 | 这套记录方式适合我自己用，团队协作还没试过。 | 判断依据、收益与限制 |
| 外部材料触发 | 最近看到一条推文说这个用法要废弃，我当时的回复是…… | 原文说了什么，自己怎么看 |
| 结论或结果前置 | 先把几个结论放在前面。 | 三两条结论，随后逐条给依据 |
| 一个反常的具体事实 | 这个岗位年薪接近二十万美元，招的不是程序员。 | 事实的来路，以及它为什么反常 |

「一个具体疑问」写作者自己遇到过的那个问题。

给读者尽快进入内容的理由。开头许下的内容在正文中兑现。
