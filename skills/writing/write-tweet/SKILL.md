# X 推文写作

一条推文说一件事。参考各管一层：[个人风格](references/voice.md) 管句子，[结构骨架](references/formats.md) 管段落顺序，[开头](references/hooks.md) 管第一行。参考里的示例只演示写法，事实来自当前材料。

## 先分场景

场景只看材料，提示语里的动词和长短参数另算：

- 用户自己写的文字里已有事情和结果，哪怕零散、不成句、没有主语，走「顺稿」。
- 只有方向或关键词，或带链接、别人的文章，走「成文」。
- 两者都有走「成文」，用户已写的句子逐字进正文，外部内容只补他没写的部分。

产出是一条成稿，分歧写进备注。

## 顺稿

保留用户的句子、用词和段落顺序，做四件事：

1. 改错别字、语病，以及写错或混搭的成语（如「兴致冲冲」）。
2. 事实只对照用户材料和常识核查，拿不准的标出，原句照留。
3. 零散处补主语、连词和指代，把碎片连成句；补的部分只含用户已写的事实和判断。
4. 按「排版」一节排版。

传了 `short` 而超一屏时正文照留，备注里写超出多少、建议删哪句；传了 `long` 时备注里写还缺什么。扩写只在用户要求时做。

AI 味检查在用户要求时按「AI 味检查」一节执行，只授权诊断，诊断结果进改动清单；没要求时交付里略过它。

完成标准：每处改动在改动清单里，段落顺序与原稿一致，字数与原稿相当，未列出的句子与原稿逐字相同。

## 成文

### 定一件事

从材料里找出一件事：一个判断、一个结果、一个发现，或一篇要转述的原文的主旨。列出支撑它的材料，每件注明来路：用户亲历、原文所说、已核实的结果。一件材料是一个动作、数字、原话、失败或适用条件。

用户给的是链接时先取全文，取不到就请用户贴正文。

材料只有方向、没有具体事时，向用户要一件具体的事：做了什么、结果是什么、哪里出乎意料。用户让直接写时按现有材料写。

完成标准：这件事一句话说得出，每件材料有来路。

### 定长度

用户传了 `short` 或 `long` 按其执行，中文说的短推、长推与传参同义。`short` 装不下时只留最具体的一件依据，其余材料进备注，由用户决定是否改 `long`；`long` 而材料只够一句时回「定一件事」要材料。

未指定时按内容判断：一个判断加一个依据是短推；步骤、多条经验、原文的几个要点或有前后过程是长推；拿不准先写短版，装不下再扩。

短推约 140 字，一屏读完。长推分段展开，每段一件短推没放下的事，长度由材料定。

### 写正文

段落顺序按结构骨架挑最接近材料形态的一种，句子按个人风格写。转述型的来源只出现在交付的发布安排里。

### 定第一行

正文写完，读 [开头](references/hooks.md) 挑第一行。

### 结尾

短推的最后一句就是结尾。长推结尾按骨架的结尾项写，说完即停；材料里没有对应内容就留空。

### 自查

- 亲历型：换个署名这条就不成立。换了仍成立，从材料里补一个细节或判断。
- 每一句都在材料范围内。
- 最后一句删掉会损失信息。删掉没损失的句子。

写完按「排版」和「AI 味检查」两节收尾。

## 排版

X 只显示纯文本，Markdown 不渲染；列表用「1.」或换行。一两句一换行，意思切换时空一行，手机上一段三行以内。话题标签、Emoji、线程序号（1/、2/）和 🧵 只保留用户材料里已有的。

## AI 味检查

调用 `/writing-ai-check`，交给新开的子代理。子代理不共享上下文，把推文全文、用户材料和指定保留的内容一并给它，正文按纯文本传。说明四件事：这是 X 推文；换行和分段是平台排版，不参与检查；材料自带的反应词和口语是作者本人的表达；转述型的来源在被引用的推文里，正文里的归属语指向它。成文场景授权它直接修正表达问题，顺稿场景只授权诊断。材料对不上的问题留在本 skill 处理。

接收修改稿后对照原意回查：第一行的具体信息、判断强度、限定条件是否还在。该 skill 不可用时完成推文，交付里写明「AI 味专项检查未执行」。

## 交付

推文正文放在代码块里，保留换行和空行。缺的材料和待确认的事实进备注，用户不回复也能直接发。

顺稿场景：正文后面给改动清单，一处一行，只写改动的词或短语；补的衔接写「补：第二句主语」。原因只在不看原句就猜不出时加一句。

```
改：兴致冲冲 → 兴冲冲；一下步 → 下一步；恢复 → 回复
补：第三句冒号引出原话
```

成文场景：第一行备选至多一条，放在正文后面。转述型另给发布安排：用户给了原推链接就引用转发，来源由被引用的推文带出；没给时交付首条回复的文案，注明可换成引用转发；用户要求链接放正文时照放。完成标准：一条推文说一件事，每句在材料范围内，第一行单独成立，长度与所选形式相称，转述型带发布安排，AI 味检查已执行或已注明未执行。
