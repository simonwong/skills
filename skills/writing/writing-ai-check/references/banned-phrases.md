# 禁用词句

## 适用范围

下列表达在作者叙述中禁用。直接引用、代码、界面原文，以及讨论这些词本身时原样保留。修复时保留原有推论、提醒和限定，不用另一组口头禅逐词替换。

## 直接删掉

这些是引导语和填充语。整句删掉，后面的内容照旧成立；不换成另一个说法。

值得注意的是、不难发现、说白了、说穿了、不可否认、众所周知、毫无疑问、综上所述、总的来说、先说结论、划重点、请记住、让我们来看看、接下来让我们、在当今……的时代、随着……的发展

### 示例

- 原文：值得注意的是，这个命令会覆盖现有配置。不难发现，旧配置不会保留。
- 改后：这个命令会覆盖现有配置，旧配置不会保留。
- 判断：保留覆盖风险和结果，删掉两处引导语。不能为了简短把风险提醒一起删掉。

## 换成具体内容

这些删掉会丢信息，写出它们指代的实际内容。

| 原表达 | 换成 |
| --- | --- |
| 更顺了、更方便了、体验更好 | 少了哪一步、哪里不再卡住、哪件事更容易完成 |
| 这意味着、意味着什么 | 直接写结果或影响，保留真实的因果关系 |
| 本质上 | 具体机制或判断依据；没有机制就删掉整句 |
| 换句话说 | 重复前句则合并；确实更易懂则只留后半句 |
| 打通、串联、形成体系 | 实际连接了哪两件事，连接后能做什么 |

### 示例

- 上下文：正文别处写了作者用任务记录列出未完成事项，下次开工先读记录，没有计时。
- 原文：加了记录以后，做事更顺了。
- 改后：下次开工时，我先看记录里还有哪些事没做。
- 判断：用正文已有的内容写清使用方式。正文别处也没有交代时，列为待核实并问哪件事发生了变化，不编造节省时间或减少错误的结果。

## 黑话

第一级是复合黑话和空壳词，在作者叙述中一律换成普通说法。

| 黑话 | 普通说法 |
| --- | --- |
| 赋能 | 让某事能做到什么 |
| 抓手 | 办法、切入点 |
| 打法 | 做法 |
| 想象空间 | 还可能用来做什么 |
| 心智 | 用户的印象、认知 |
| 能力沉淀、商业闭环、降本增效、底层逻辑、顶层设计、全链路、组合拳 | 写出它指的那件事 |
| 干货、必看、家人们、宝子、破防、yyds | 删掉，或写出它指的那件事 |

第二级是在技术语境里有本义的词：闭环、沉淀、对齐、拉齐、颗粒度、抽象、下沉、复用。看紧邻处有没有落点——定义、文件路径、代码、具体的流程步骤、明确的两方。有落点保留；只是给一件普通事贴标签时，换成具体动作。

- 「把决策沉淀成 `docs/specs/2026-09-10-主题.md`」有落点，保留。
- 「团队能力持续沉淀」没有落点，改成实际记下了什么、记在哪。
- 「generate → review → fix 的小闭环」有落点，保留。
- 「形成业务闭环」没有落点，写出连接了哪两件事。
- 「栈区堆区是操作系统抽象出来的」是本义，保留。

## 模型偏爱的抒情词

在非虚构稿件中，这些词多用来给普通事情加分量，删掉或改成具体描述。

安放、抵达、微光、褶皱、温度、注脚、坐标、锚点、底色、回响

写实际的光线、温度、坐标时不受影响。

## 空泛断言

只宣布重要性、不给具体内容的句子。删掉，或换成它想指的那件事。

意义重大、影响深远、值得深思、原因是结构性的、后果是真实的、这背后是更大的命题、数据不会说谎

结尾出现时代、文明、未来、世界、历史、奇迹、所有人这类大词，而正文没有在这个尺度上讨论过时，同样处理。

## 格式

- Emoji：段首连续 Emoji、每个小标题各配一个 Emoji，删掉。句末的语气 Emoji、表格里作取值的 ✅ ❌、其他确有标记作用的用法保留。判的是模板化，不是数量。
- 加粗：按加粗的内容判。加粗的是术语名、字段名、列表项标题时保留；加粗的是一句判断或口号时改回正文。每一节末尾各有一句加粗结论、彼此并不相邻时，同样是模板化，一并指出。
- 代码块、表格，以及供读者复制使用的模板区，不参与格式检查。
